# Dev Kumar — Oracle GPU infrastructure portfolio

Responsive portfolio tailored to Oracle Careers requisition 345542. The site pairs an original GPU rack background with motion, rotating focus text, an interactive qualification and recovery diagram, measured outcomes, all 15 supplied experience bullets, and the supplied project links.

- `index.html` — full portfolio, all experience bullets, projects, links, and education
- `styles.css` — responsive editorial layout, animated background, and motion treatments
- `script.js` — focus text rotation, interactive fleet lifecycle diagram, scroll reveals, and project filters
- `compute-readiness.webp` — optimized GPU infrastructure background artwork; `compute-readiness.jpg` is the higher-resolution source image
- `ROLE_RESEARCH.md` — Oracle requisition 345542 and OCI GPU validation research

Every distinct project in the request has a `SourceCode` link. `Technical Demo` appears only for TradeSentinel, AskMyStore, Strangers, and Oxide-HV, where the user provided demo URLs. The portfolio has no LinkedIn link and no footer.

To preview, serve this folder with any static HTTP server. GitHub Pages deploys from the repository root through `.github/workflows/pages.yml`.
